## Conteudos estudados

```text
String  -> texto
int     -> numero inteiro
double  -> numero decimal
boolean -> verdadeiro/falso
```

```text
+ -> soma ou concatenacao
- -> subtracao
* -> multiplicacao
/ -> divisao
% -> resto da divisao
```

```text
>  -> maior que
<  -> menor que
>= -> maior ou igual
<= -> menor ou igual
== -> igual
!= -> diferente
```

```text
if      -> se
else    -> senao
else if -> senao se
```
